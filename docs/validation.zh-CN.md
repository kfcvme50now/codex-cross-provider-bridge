# 0.3.0 验证说明

## 自动测试

发布前本机执行：120 项 Python unittest 通过；Windows 配置脚本测试通过；PowerShell 全部脚本语法检查通过。Ubuntu 与 Python 3.11 的结果由 GitHub CI 另行验证。

Python unittest 使用合成会话、临时 SQLite 和本地模拟上游，覆盖：

- 请求清理、工具调用 ID 配对、窄范围兼容重试。
- 桌面和 CLI 原生来源识别、浏览器边界与原样转发。
- 官方登录信息的路由隔离，官方 provider 模板保持原生上游。
- 第三方和 `cn_official` 配置投影、别名保留、并发写入与恢复。
- 普通流和压缩流的超时分类，以及系统 HTTPS 代理。
- CODEX_HOME、CC Switch 数据目录、自定义数据库、非默认端口和 wrapper 更新。

Windows 的 `Test-CodexBridgeConfig.ps1` 单独验证配置修复、备份和恢复等脚本行为。

## 原生客户端验证

2026-10-05 已在 Windows、Codex 桌面内置 CLI 0.160.0 与 CC Switch 3.20.4 组合上验证：

- DeepSeek Flash 正常请求、手动压缩、自动压缩、重新打开和继续。
- GPT 官方路由的正常请求、手动/自动压缩、恢复和继续；独立验证使用 gpt-6-luna / low。
- DeepSeek 到 GPT 再返回 DeepSeek 的历史继续。
- 当前 GPT 对话的命令、文件和网页工具，以及独立请求的图片输入。
- 一次切回 GPT 的兼容和压缩请求历时约 132 秒后完成。时长包含兼容重试，不能全部视为上游计算时间。

真实请求通过原生 Codex app-server 发出，不用最小 HTTP 探针替代。成功依据为 `turn/completed`、压缩记录及最终流完成，而非模型列表。

本机验证曾有一次模型目录连接重置，随后刷新恢复；一次独立文件读取被自动审批策略拒绝。独立会话的拒绝不等于 Bridge 转发失败，但也不能记作成功执行该文件命令。

这些结果验证了既有修复。0.3.0 新增的环境与端口参数化通过本地回归验证，未再次发送收费模型请求。其他操作系统、模型和 provider 组合仍需自行验证。

## 发布检查

公开版本不包含本机请求记录、历史副本、凭证、服务 PID、会话 ID、数据库和恢复归档。运行状态和测试报告保留本地。

发布使用 Gitleaks 检查工作树和 Git 历史，并执行 `scripts/check_publication.py`。静态检查和秘密扫描不能替代运行时验证，也不能保证未来加入的私有数据自动安全。
